# Scratchin' Charter
A chart editor for Custom Chart Support V2, a (work-in-progress) mod for Scratchin' Melodii by LJ LephemStar.

# Notice
This repository is a work-in-progress. It's also likely that work on the mod in general will be slow.

# Third-party Libraries
- [Svelte](https://svelte.dev/)
- [Svelte Material UI (SMUI)](https://github.com/hperrin/svelte-material-ui/) by [hperrin](https://github.com/hperrin/)
- [WaveSurfer](https://github.com/katspaugh/wavesurfer.js/) by [katspaugh](https://github.com/katspaugh/)
- [animation-timeline-control](https://github.com/ievgennaida/animation-timeline-control/) by [ievgennaida](https://github.com/ievgennaida/)
- [localForage](https://github.com/localForage/localForage)
- [Monaco](https://microsoft.github.io/monaco-editor/)
- [MDsveX](https://github.com/pngwn/MDsveX/) by [pngwn](https://github.com/pngwn/)
